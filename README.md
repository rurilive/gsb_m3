# ostat

一个只用 Python 标准库的小仓库，提供"有序统计结构"。

## 现状

- 包名 `ostat`，核心类 `SortList`，位于 `ostat/stat.py`。
- 内部只有一个始终保持升序的 list。
- `insert` 用二分找位置后插入，`remove` 二分定位后删除；
  两者都要用列表切片在中间搬动元素，代价随元素个数线性增长。
- `kth` 返回第 i 小（零基），越界抛 `StatError`。
- `rank` 返回严格小于给定值的元素个数。
- `count_range` 返回闭区间内的元素个数。
- 所有自定义异常继承自 `StatError`。

## 问题

每次中间插入或删除都要搬动一整个数组；规模一大，改动一次的代价就
随元素个数线性上涨。

## 目标

把核心从有序数组换成以平衡树（带子树大小的顺序统计树）为核心的结构，
让按排名取值、求排名、区间计数、前驱后继这些操作都做到对数级，同时
保持现有口径不变，并与朴素有序数组对同一批数据给出的事实逐项一致。
