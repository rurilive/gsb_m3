# orderstat

一个只用 Python 标准库的小仓库，提供无序序列上的次序统计工具集。

## 现状

- 包名 `orderstat`，核心类 `Selector`，位于 `orderstat/seq.py`。
- 内部只有一份平铺的 list，元素按构造给出的顺序保存，允许负数与重复值。
- `select_kth(rank)` 把整段复制一份再排序，取排序后的第 rank 个。
- `smallest_sum(count)` 把整段排序后取前 count 个逐项累加，count 为 0 返回 0。
- `median()` 把整段排序，奇数长度取中间那个，偶数长度取中间两个的均值。
- `pairwise_median(other)` 各自排序后归并合并，再取整体中位数。
- `sorted_copy()` 返回一份排好序的副本，供内部复用。
- `replay(values, queries)` 在副本上依次回放一串查询，返回末态与逐步返回值。
- 所有自定义异常继承自 `OrderStatError`。

## 问题

每个查询都要把整段重新排序一遍：求第几个最小、求前几个最小之和、求中位数
都走同一条全排序的路，两序列中位数还要额外归并一次。单次查询就要碰过整段
全部元素，查询一多就反复把同一段排序，中间没有任何选择结构或堆可供复用；
一次查询到底比较了多少个元素，序列上也没有任何计数可供对照。结果虽然都对，
但代价随元素个数与查询次数一起上涨。

## 目标

把核心从整段全排序换成以快速选择与堆维护为核心的次序统计工具集：第几个最小
用划分与随机基准加三路划分去做，并对最坏情形给出确定口径；前几个最小之和用
堆维护而不整段排序；两个有序序列的中位数在对数级完成。每条能力都另给一条
独立做法（全排序、堆、分治）与该路逐项对照，正负数、重复值与混排下的口径
保持一致，并对外暴露选择路与全排序路的比较次数计数，把两条路的差距量出来。
改造后两条路对同一批数据给出的事实必须逐项一致，原先那套全排序路径保留下来
做对照。
