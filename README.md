# slopeopt

一个只用 Python 标准库的斜率型动态规划最优化工具包。包内模块 core.py 提供
OptKit 与 Program：状态转移形如 dp 取此前某个状态加上一个含下标的线性代价的
最小值，optimize 求最小代价下的 dp 序列与最优决策下标序列，compare 对同一批
输入给出逐项结果作为后续高效路径的对照事实。

## 现状

求解一律靠朴素做法：对每个下标枚举全部更早的下标，逐个把 dp 值与代价加起来
再取最小，最小下标并列时取更小的下标；dp 的首项直接取第一个权值本身；每一步
的比较次数与候选转移总数如实报出。规模小时直观可靠，结果一眼能看穿。

## 问题

朴素做法在规模一大就退化：两个下标两两配对，是平方量级，序列一长就慢到难以
在合理时间里给出答案；实现既没有把规模压下来的手段，也没有任何计数能说明一
条更聪明的做法到底省了多少，更谈不上按斜率切点或按查询点取最小这类能压住
规模的口径，快了之后对不对也没有人替它把关。

## 目标

把 OptKit 从朴素枚举扩成一套高效的最优化工具集：其一用单调队列维护下凸包，
按斜率切点取最优，斜率单调时线性；其二用李超树在任意查询点上取最小值，不要求
斜率单调。两路对同一批输入逐项一致，并与朴素路一致，dp 值、最优决策下标与每步
比较次数都要能对上；决策下标并列时取最小的口径保持不变；暴露比较次数、下凸包
弹出次数与李超树节点访问次数等规模计数对照；覆盖空序列、单元素、斜率单调递增、
递减与相等、截距全同、查询点重复、权值很大与 dp 值超出定长整数等边界。
