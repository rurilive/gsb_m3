# tabox

纯标准库的分隔符文本小包，无外部依赖。

## 现状

tabox/reader.py 提供最简单的定长 CSV 读取器 CsvReader：

- read：先按换行断行，再按逗号切分每行，把字段两端成对的双引号剥掉
- text：构造时传入的原始文本
- tabox/__init__.py 只导出 CsvReader

分隔符写死是逗号，引号字符写死是双引号，没有方言、没有转义规则、没有行终止符
配置，引号里的逗号或换行会被当成普通字符误切，没有类型推断，也没有把解析结果
写回文本的能力。

## 目标（见任务描述）

把 tabox 从朴素读取器扩成完整的分隔符文本方言工具：分隔符、引号字符、转义
规则、行终止符都可配，不同方言下解析结果正确；引号内的分隔符与换行不算字段
边界，引号自身的转义按方言处理，未闭合引号 fail fast；可选的类型推断把整列
推断为整数或浮点或字符串，混列回落字符串；解析结果能按指定方言序列化回文本，
解析再序列化再解析幂等；首行可声明为表头并与数据行分离，数据行列数不齐按明确
策略处理。全部仍在 tabox 里，纯标准库，边界 fail fast 抛异常，异常继承 TaboxError
基类。约束：

- 现有行为与 tests/test_reader.py 基线保持一致（基线一个字不改）
- 新行为另开 tests/test_dialect.py，用固定文本断言
- 纯标准库，不引第三方
