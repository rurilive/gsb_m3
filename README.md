# bitidx

纯标准库的内存记录集与查询雏形，无外部依赖。

## 现状

bitidx/recordset.py 提供一张具名列记录集：

- RecordSet(columns)：一张表，各列长度必须相等，非整数立刻报错
- get_value、get_row、scan：按列名与行号逐值或整列取回，都对外只读
- select：唯一的查询入口，逐行判断某列是否等于给定值，返回命中行号集合
- insert、delete：末尾插入一行、按行号删除一行，其后行号依次前移

## 问题

查询只有逐行判一遍这一条路，每加一个条件就要把整列再扫一遍，
条件之间也没有任何按位组合的办法；命中行号集合每次都是重新算出来的列表，
既给不出总数、也分不了页；表里删掉几行之后，之前算出来的行号也全乱了。

## 目标

在当前基础上补出位图索引、位运算组合查询、压缩位图、计数分页与排序键，见任务描述。约束：

- 现有行为与 tests/test_scan.py 基线保持一致（基线一个字不改）
- 纯标准库
- 组合查询的结果必须与逐行扫描一致，压缩后位运算仍正确
