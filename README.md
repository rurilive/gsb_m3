# tarjanlca

纯标准库的森林最近公共祖先雏形，无外部依赖。

## 现状

tarjanlca 里的 tree 模块提供一片用父指针表示的森林，允许多个连通块：

- Tree(parents)：字典建森林，根记 None，构造时校验父结点存在与无环
- nodes、roots：取全部结点与全部根结点的升序列表
- path_to_root、depth：沿父指针逐级上溯得到到根的路径与深度
- lca：先标记一端到根的整条路径，再让另一端上溯找第一个命中点
- lca_all：对一批点对逐个调用朴素最近公共祖先

## 问题

每次询问都各自把一端的整条到根路径重新标记一遍，再让另一端上溯比对，
标记的次数随询问数增长、上溯的步数随深度增长，询问一多、树一深就拖不动。

## 目标

在当前基础上补出塔扬离线解与逐询问标记两条路径，并逐项对照，见任务描述。约束：

- 现有行为与 tests/test_tree.py 基线保持一致（基线一个字不改）
- 纯标准库
- 两条路径对同一批森林的全部询问必须逐项一致

## 运行

```bash
python3 demo.py
python3 -m unittest discover -s tests
```
