# idgen

订单系统的本地 ID 生成器，纯标准库。

- `idgen/gen.py`：`IdGenerator.next_id()`，毫秒时间戳左移 16 位拼自增计数
- `tests/test_gen.py`：行为基线
- `demo.py`：连续生成演示

## 实现说明

- 位布局：41 位毫秒时间戳（自定义纪元起）| 10 位实例号（0-1023）| 12 位序列（每毫秒 4096 个）
- 时间戳在高位，ID 随时间整体递增，按 ID 排序即按时间排序
- 时钟回拨 ≤10 秒：冻结在最后一次时间戳上继续递增序列，保证单调不重复
- 回拨超过阈值：抛 `ClockMovedBackwardsError`，让运维立刻发现而不是安静出重号
- 序列打满：自旋等下一毫秒再出号，绝不绕回 0 复用旧序列
- 实例号写重：启动时向 `FileInstanceRegistry`（共享目录租约）抢注实例号
- 已被存活实例占用则抛 `DuplicateInstanceError`，进程退出或租约过期后自动释放
- 压测：单实例出号约 1µs/个，三实例并发互不干扰
