# entropack

一个纯标准库的 Python 熵编码库。

## 现状

当前只有最朴素的实现。`entropack/codec.py` 里的 `FixedWidth` 把字母表里
每个符号都用同一个固定位宽编码，位宽只由字母表大小决定，跟符号实际出现
的频次完全无关。编码就是按索引取定长二进制位，解码要另外告诉它符号个数，
因为末尾补的零位跟真实符号无法区分。这里没有频次统计，没有变长编码，没有
前缀码，也没有任何树结构。

基线行为由 `tests/test_codec.py` 锁定，包含字母表构建、位宽计算、定长
编码打包、按个数解码、以及越界与类型错误的语义。

## 目标（见任务描述）

把 `entropack` 从定长编码扩成哈夫曼变长编码，公开能力与可断言口径以任务
描述为准。目标实现不在本基线内，`demo.py` 第二段与本文末尾的说明均为占位。

## 运行

```
python3 demo.py
python3 -m unittest discover -s tests -v
```
