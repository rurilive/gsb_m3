# matpow

一个只用 Python 标准库的线性递推工具包。包内模块 recur.py 提供 RecurKit 类，
围绕常系数线性递推做最基础的几件事：nth_term 求第n项，prefix_sum 求前n项和，
nth_term_nonhom 求带附加常数项的非齐次递推的第n项；另配 mat_mul 做朴素矩阵
乘法，mat_pow 做逐次相乘的矩阵幂。

## 现状

求第n项一律从初值按递推式一项一项往上推，每一步整数加乘之后立刻对模取余，
推到目标项为止；前n项和就是把逐项推出来的每一项累加起来再取模；非齐次递推
在后面挂一个固定的附加常数项，同样逐项推。矩阵乘法用三重循环逐项累加，矩阵
幂把同一个矩阵连乘指数那么多次。规模小时直观可靠，结果一眼能看穿。

## 问题

练项数一旦变大，逐项迭代就是线性量级：要第几百万项就得推几百万步，顶不住。
矩阵幂同样落后：指数多大就要做多少次矩阵乘法，每次乘法又是立方量级的循环。
实现既没有把规模压下来的手段，也没有任何计数能把逐项迭代步数与快速幂乘法
次数摆在一起对照，两套路子之间更没有互相核验的机制。

## 目标

把 RecurKit 从朴素递推扩成一套快速求值工具集：把递推式转成转移矩阵，用矩阵
快速幂按二进制拆分指数求幂，支撑第n项、前n项和、带附加常数项的非齐次递推；
新老两路对同一批输入逐项一致，并暴露逐项迭代步数与快速幂乘法次数的差距；
覆盖指数为零、初值全零、模为一、递推阶数为一、系数为负等边界；固定输入重复
跑结果一致且不依赖模块级可变状态；异常统一继承 RecurErro 基类并快速失败；
基线那条朴素路径一条都不许删。
