# routex

一个极简的纯标准库路径路由包，Python 3.10+，无外部依赖。

## 现状

`routex/router.py` 只提供最朴素的线性匹配器 `LinearRoute`：注册的路径存成
一个按注册顺序排列的列表，匹配时对每条路径做整串逐字符比较，完全相同的第一条
就算是命中。没有前缀树，没有参数段，没有通配段，也没有最长前缀或优先级的概念。

- `LinearRoute.add(path, handler)`：注册一条静态路径，重复注册报错
- `LinearRoute.remove(path)`：注销一条路径，未注册则报错
- `LinearRoute.match(path)`：按注册顺序整串比较，命中返回
  `Match(handler, params)`，其中 `params` 恒为空字典；未命中返回 `None`
- `LinearRoute.routes()`：按注册顺序列出全部路径

路径约定以斜杠开头，根路径为单个斜杠，空段、缺前导斜杠、尾斜杠一律判为非法
并立刻报错。路径里的冒号与星号目前都只是普通字符。

## 目标（见任务描述）

前缀树：路径按段挂到树上，插入与查找都按段遍历，静态段精确到叶节点，匹配
结果与线性口径一致。

参数段：形如冒号开头的段在匹配时捕获到命名参数，参数值与请求路径对应。

通配段：匹配剩余全部段的通配段与匹配单段的通配符，通配与参数共存时按静态
优先于参数优先于通配的顺序选定，并断言。

优先级与最长前缀：同一路径被多条规则匹配时按优先级和注册顺序给出确定结果。

回溯：一条分支走到头不匹配时能回溯尝试其它分支，混合静态、参数、通配的复杂
路径仍返回正确结果。

边界：空路径、根路径、重复注册同路径、非法段（空段或非法参数名）按明确口径
fail fast 或处理，并断言。

约束：

- 基线测试 `tests/test_router.py` 一字不改，且必须保持全绿
- 新行为另开测试文件 `tests/test_trie.py`，用固定路径集断言
- 纯标准库，不引入任何第三方依赖
- 自定义异常继承 `RouteError` 基类

## 运行

```bash
python3 demo.py                          # 静态匹配演示
python3 -m unittest discover -s tests -v  # 行为基线测试
```
