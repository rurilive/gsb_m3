# seqalign

序列比对与编辑距离的朴素求解器，纯标准库，无外部依赖。

## 现状

`seqalign/core.py` 提供 `SeqAlign`：

- `lcs_length(a, b)`：最长公共子序列的长度，枚举两个串的全部子序列组合取最长
- `lcs_string(a, b)`：一条具体的最长公共子序列，按枚举顺序取第一条达到最长长度者
- `edit_distance(a, b)`：最少插入、删除、替换次数，对每一步枚举三种操作再递归
- `indel_distance(a, b)`：只允许插入删除的最少步数，等于两串长度之和减两倍最长公共子序列长度
- `lcs_substring(a, b)`：最长公共子串的长度，枚举 `a` 的全部子串去 `b` 里查找
- `lcs_prefix(a, b)`：最长公共前缀的长度，从首字符逐个往下比

异常基类是 `SeqAlignError`，参数不是字符串抛 `TypeMismatchError`，空串非法时抛
`EmptyInputError`。全部路径都靠枚举，结果确定，但长度一长枚举的状态数就指数甚至
更高量级地膨胀。

## 问题

没有按二维动态规划求最长公共子序列长度的做法，枚举全部子序列组合在中等长度上就
扛不住；编辑距离对每一步枚举三种操作递归，同一对前缀被反复重算；只允许插入删除的
距离没有独立口径去和编辑距离互相印证；最长公共子串与最长公共前缀也没有可对照的
第二条路径与状态数计量。
