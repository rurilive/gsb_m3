# dagwer

一个纯标准库的 Python 有向无环图校验包。

## 现状

当前只提供最朴素的成环检查：`DagCheck` 持有边集合，用深度优先遍历判断是否成环。
没有拓扑序、没有分层、没有最小环、没有增量校验能力。

## 目标（见任务描述）

把 dagwer 从成环检查扩成依赖图校验器，提供确定拓扑序、最长路径分层、
自环与平行边处理、最短环路径、增量校验等能力，全部仍在 dagwer 包内，
纯标准库实现。

## 运行

```
python3 demo.py
python3 -m unittest discover -s tests -v
```
