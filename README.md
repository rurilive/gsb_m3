# persistx

一个只用 Python 标准库的序列版本化统计工具包。包内模块 pst.py 提供 PersistSeq 类，
把一条序列的历次修改各自留一个版本：set 改一个位置生成新版本，range_sum 求区间和，
range_min 与 range_max 求区间最值，kth_smallest 求区间第几小，version 与 use 看和切
当前版本，stats 出内存与版本计数快照。

## 现状

版本留痕走的是最直白的路子：每次单点修改，先把当前版本的数组整份复制一份，在副本
上改掉一个位置，把副本追加成新版本，旧版本那份数组原样不动。区间求和拿目标版本的
副本切片后逐项累加，区间最值逐项取极值，区间第几小切片后整段排序再取下标。规模小
时结果一眼能看穿，也从来没出过错。

## 问题

整份复制让内存与时间都随修改次数线性上涨：改一次就是一次整份拷贝，查一次就是一次
整段扫描，版本一多就顶不住了。历史版本虽然全量留痕，却没有任何按需共享的结构能
把代价压下来，既没有以可持久化线段树为核心的路径复制，也没有多版本共存下对数级
增长的空间口径，更没有静态区间第几小这类需要对前缀建树的进阶查询。

## 目标

把 PersistSeq 从整份复制扩成以可持久化线段树为核心的版本化统计工具集：单点修改只
新建从根到叶的一条路径节点，旧版本根指针复用未变子树，多版本共存而内存对数级增长；
支持任意历史版本上的区间求和与区间最值；支持静态区间第几小的查询，对一个版本前缀
建树、两版本相减定位第几小；支持单点修改后按时间回溯任取旧版本。边界要覆盖空序列、
单元素、连续多次修改、查询旧版本、下标越界快速失败；异常统一继承 PstError 基类；
基线那条朴素路径一条都不许删，新老两条路径对同一批数据的事实必须逐项一致；固定输入
重复跑结果一致，不依赖模块级可变状态。
