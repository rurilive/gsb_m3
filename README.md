# framefmt

一个纯标准库的记录编解码包，无外部依赖。日志落盘、消息传输、二进制文件交换
这类场景都要把一条记录编码成字节再从字节还原回来，framefmt 就是干这件事的那
一层。

## 现状

- `framefmt/codec.py`：`LineCodec` 把一条记录当成若干定宽字段，编码时逐字段
  补齐宽度后拼成一行字符串，解码时按同样的宽度一行一行切回来。
- `framefmt/__init__.py`：只导出基线类 `LineCodec`。
- 一条记录就是一行文本，没有长度前缀，没有字段类型，没有校验和，也没有变长
  编码。

现有实现把记录压成定宽文本行，字段是全是文本，整数、浮点、布尔、字节串与
嵌套记录都表达不了；一行里没有长度信息，从连续字节流里切出多条记录无处下手；
一行只靠固定宽度自描述，字节被改动一个也无从察觉；字段宽度一旦定死，小值也
要占满整宽，短记录与长记录一视同仁。改造前的基线行为锁在 `tests/test_codec.py`，
改造后这个文件一字不改且必须全绿。
