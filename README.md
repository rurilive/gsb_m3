# mincircle

一个只用 Python 标准库的最小圆覆盖小包。

## 现状

核心是 circle 模块里的 brute_min_circle。求覆盖一批点的最小圆，就把所有点两两配对求出每一对确定的最小圆，再枚举所有三点组合求出过这三点的外接圆，把这些候选圆逐条记下来；然后拿每一个候选到全部点里逐点核验，能包住全部点的才算合格，在合格的候选里取平方半径最小的那一个。点用整数坐标，圆心与半径用精确有理数、以平方半径参与比较。

## 问题

这套做法整体是立方甚至更高的。点一多，点对与三点的组合数按点数的立方增长，每个候选又要再扫一遍全部点核验，很快就撑不住。中间结果完全没法复用，每加一个点都要推倒重来。

## 目标

在保住既有对外行为的前提下，把最小圆覆盖改成增量加随机的期望线性做法：逐个加入点，若当前点已在圆内就跳过，否则把该点定为圆上一点、以它为界重扫已经加入的点，必要时再定第二个边界点、重扫一遍确定新圆。处理顺序由自实现的确定性序列与固定种子决定，不依赖系统随机源。并保留一条独立做法，即枚举两点与三点组合的朴素口径，两条路对同一批固定输入逐项一致。圆心与平方半径都以精确有理数给出。

## 运行

在仓库目录下：

```
python3 demo.py
python3 -m unittest discover -s tests
```
