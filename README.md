# lfux

一个纯标准库、无外部依赖的 Python 缓存包。眼下只提供最朴素的定容缓存
FifoCache：容量固定，内部用一个字典存键值，满的时候按插入先后淘汰。

## 现状

lfux/cache.py 提供 FifoCache：

- FifoCache(cap)：固定容量的缓存，容量非正数在构造处抛 ValueError
- put(key, val)：写入并返回值，键不存在且已满时先淘汰最早插入的那一条
- get(key)：返回对应值，键不存在返回 None
- peek(key)：与 get 同义，且不改变任何内部状态
- keys()：当前全部键，顺序为插入先后
- len() / in：条目数与成员判断

它只按插入先后淘汰，从来看访问的好坏，也从不记录访问频次。

## 问题

冷热不分。写进来的先后决定了谁先被挤走，一个被反复读取的热键只要插得早，
照样会被一个只写一次、再没人读的冷键挤出去，缓存命中率因此上不去。
