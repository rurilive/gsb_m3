# orderbook

纯标准库的内存订单列表演进，无外部依赖。

## 现状

orderbook/engine.py 提供一个 Engine 与一条 Order：

- place：下单，追加一条订单并返回订单号；只做基础校验，账户非空、
  方向只能是 buy 或 sell、价格与数量都是正的 int，不合法抛 ValueError
- cancel：撤单，把对应订单从列表删掉，订单不存在抛 KeyError
- open_orders、depth：按到达顺序取回挂单、取回某一侧的挂单
- trades：成交流水，现状下恒为空
- len：未撤订单条数

现在还没有订单簿：不维护买一卖一档位，不做价格优先与时间优先的排序，
新订单不会和对手盘撮合，也不会产生任何成交；没有市价单、没有部分成交、
没有盘口聚合，也没有量守恒与无交叉的不变量。

## 问题

下单只往一个列表里追加，同价与不同价的订单混在一起按到达顺序排，买家
想拿最优价、卖家想拿最高价都没有依据；新单进来不看对手盘，买卖双方即
使价格能成交也各自挂在簿上，永远碰不到；没有成交，也就没有成交流水可
追；数量只能整单挂着，吃不满的残量留不下来，撤也只能撤整单；想看一眼
买卖前几档的价位与挂量，只能自己把某一侧全枚举再数；买盘价格高过卖盘
这种交叉态没有任何检查，撮合前后量对不对也没有口径。

## 目标

在当前基础上补出价格时间优先的订单簿、逐档撮合与部分成交、盘口聚合与
市价单口径，约束：

- 现有行为与 tests/test_orders.py 基线保持一致（基线一个字不改）
- 纯标准库，不引第三方
- 不变量：任意时刻买盘价格不高于卖盘价格，下单量等于成交量加残量

## 运行

```bash
python3 demo.py
python3 -m unittest discover -s tests -v
```
