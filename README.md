# mcfx

纯标准库的有向网络流工具包。包名 mcfx，核心在 mcfx/flow.py，主类是 FlatMcf。

## 现状

- 邻接表加边：add_edge(u, v, capacity, unit_cost)，平行边各自独立。
- max_flow(s, t)：朴素逐条增广求最大流，只盯容量，不看费用。
- path_cost(s, t)：残量网络上单条最短路的费用，当作粗略参考。
- has_feasible(s, t, need)：能否把 need 单位流量送达。
- 非法节点与非法容量即刻抛异常，统一继承 McfError。

## 问题

既最大又最省这件事当前答不了。max_flow 给的是流量最大但不保证总费用最小；
path_cost 只取一条路径，既不保证是最大流下的最小值，也没法覆盖多条路径叠加
的情形。想做"在最大流前提下费用最小""恰好送指定流量且最省"，现有能力都不够。

## 目标

把 FlatMcf 扩成以最小费用最大流为核心的网络流工具：维护残量网络与反向负费用边，
在最大流前提下沿最短路逐次增广把费用压到最小；补上指定流量最小费用、费用下限
断言、增广与最短路查询计数、平行边与零容量、自环与负费用的边界处理，以及固定
输入可复现的确定性。基线那套朴素增广不许删，两条路对同一批数据的事实要对得上。
