# molib

内存里的朴素离线区间查询，纯标准库，无外部依赖。

## 现状

`molib/offline.py` 提供 `BruteQueries`，内部只有一个数组，所有区间统计
都按最朴素的方式做，每个查询各自独立地把区间扫一遍：

- `distinct(l, r)`：逐项收进集合，再数集合大小
- `mode_count(l, r)`：把区间内每个值的出现次数逐项数出来，再取最大
- `sum_of_squares(l, r)`：把区间内每个值的出现次数逐项数出来，再求平方和
- `brute_cost(l, r)`：按朴素口径给出该查询要逐项扫过多少元素

区间一律是左闭右开的半开区间 `[l, r)`，下标从 0 数起。

## 问题

每个查询都从头把区间重新扫一遍，查询之间没有任何复用：`distinct` 每次
重建一个集合，`mode_count` 与 `sum_of_squares` 每次重建一份计数字典。
查询一多、区间一长就白扫，同样的元素被反复数过很多遍。

## 目标

在当前基础上，以莫队算法为核心把 `BruteQueries` 扩成离线区间查询工具，
补出分块排序、指针两侧移动的增量维护、指针移动计数、奇偶优化、以及
对只方便加不方便删的统计口径的回滚处理，见任务描述。约束：

- 现有行为与 `tests/test_offline.py` 基线保持一致（基线一个字不改）
- 纯标准库
- 逐项重扫那套路径保留，两条路对同一批数据给出的事实必须一致

## 运行

```bash
python3 demo.py
python3 -m unittest discover -s tests -v
```
