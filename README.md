# konig

一个只用 Python 标准库的二分图小工具。包内模块 graph.py 提供 NaiveGraph 类，
维护一张二分图：左侧一组点、右侧一组点，边用有序对逐条登记。add_left 与
add_right 登记点，add_edge 逐条加边（自环与重边当场拒绝），naive_max_matching
求最大匹配边集，naive_matching_size 求匹配条数，naive_min_vertex_cover 求点
覆盖，matched_to 在已求出的匹配里回查左侧点配到的右侧点。

## 现状

求匹配用最直白的增广路深搜：每个左侧点都深度优先找一条增广路，路径上走到哪
算哪，不做任何剪枝与优化，找到一条就翻转配对，找不到就换下一个起点。求点覆盖
直接枚举左侧点里该选的子集，逐个验证是否盖住全部边，只取规模最小的那个。

## 问题

增广路搜索没有任何优化，同一张图反复重搜，图一大、路一长就很慢。点覆盖的枚
举随点数指数膨胀，而且只在左侧点里挑，范围被限死：右侧点一个也选不了，图稍
大就直接撑不住，也拿不到真正的最小覆盖。

## 目标

保留现有入口与返回值形态不动，在其上叠加以柯尼希定理为核心的升级：从最大匹
配出发沿交错路标记可达点，用可达左点与不可达右点构造最小点覆盖，使覆盖大小
等于匹配条数；再用一条独立的子集枚举做法在小图上逐项核对；覆盖空图、无边、
完全二分图、含孤立点、多组最大匹配并列等边界；并列时按定点编号字典序取，口
径写死；异常统一继承 Erro 基类；全程纯标准库。
