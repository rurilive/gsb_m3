# syndigest

纯标准库的数据对账小包，无外部依赖。

## 现状

syndigest/sync.py 只提供最朴素的全量同步：

- FullSync(items=None)：持有一张键值表，默认空表
- set(key, value) / get(key, default=None)：写入、读取一个键值
- __contains__ / __len__ / keys() / items()：查键、计数、列键、取副本
- snapshot()：整张表的独立副本
- sync_to(peer)：把本地整张表原样发给对端，返回本次发出的条目数
- receive(payload)：收到整表就用它整体覆盖本地，不做任何合并
- sent_entries：累计已发出的条目数
- 没有摘要、没有差集、没有版本，也没有冲突合并

tests/test_sync.py 把上述基线行为锁住，一字不改。

## 目标（见任务描述）

在现有 FullSync 之上把 syndigest 扩成摘要驱动的反熵同步：把键空间按确定方式
分段并求每段摘要，相同内容摘要相同、段内变化摘要随之变化；两方交换摘要后只对
不一致的段深入细分递归，直到定位到具体不一致的键，过程确定性可复现，且传输量
小于全量；多个节点用固定随机种子反复随机挑对端做反熵，若干轮后数据完全一致，
收敛轮数与数据规模关系合理；同一键两侧不同值时按版本或确定规则合并，合并满足
幂等与交换律，不会来回振荡；随机数挂在节点自己身上，不取自模块级全局状态，相同
初始数据与种子可完全复现；空表、单键、单方有键与分段边界都正确，非法摘要格式
fail fast。全部仍在 syndigest 包内，纯标准库。
