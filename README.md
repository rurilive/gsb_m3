# idgen

订单系统的本地 ID 生成器，纯标准库。

- `idgen/gen.py`：`IdGenerator.next_id()`，毫秒时间戳左移 16 位，低 16 位 = 实例号 + 自增计数
- `tests/test_gen.py`：行为基线
- `tests/test_snowflake.py`：多实例唯一性、顺序、时钟回拨、大促并发
- `demo.py`：连续生成演示

## 实现说明

- 位布局：`(毫秒 - EPOCH) << 16`，低 16 位 = 实例号 4 位（0-15）+ 毫秒内自增 12 位（每毫秒 4096 个）。
- 实例号在自增高位，同一毫秒内各实例的号天然有序，整体按 ID 排序即按时间排序。
- 时钟回拨：回拨期间沿用最后毫秒继续自增，不回头，因此不出重号、单调性不变。
- 回拨期间自增位也打满：等待时钟追上，超过 `max_wait_ms` 抛 `ClockMovedBackwardsError`，宁可报错不出重号。
- 大促打满自增位：自旋等到下一毫秒归零继续，单实例上限 4096 个/ms，三实例合计 12288 个/ms。
- 实例号写重：可选 `FileInstanceRegistry` 在共享目录占位 + 周期心跳，同号活实例启动即抛 `InstanceIdInUseError`；占位超时（默认 10s 无心跳）才允许接管。
