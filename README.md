# zstr

纯标准库的字符串前后缀工具雏形，无外部依赖。

## 现状

zstr/naive.py 提供四条朴素能力：

- z_array：每个后缀与原串的最长公共前缀长度数组，对每个位置从头逐字符比较
- occurrences、count：模式在文本里出现的全部起点（升序、允许重叠）与次数，每个起点逐位对齐比较
- min_period、is_periodic：最小整周期长度与是否存在真周期，靠逐位试
- TextTools：绑定一段文本，方法同上并累计逐字符比较计数，可读取与清零

所有结果都对，但每个起点都要重新比较一遍，没有一趟线性求出全部 Z 值的
做法，也没有扩展 KMP 与独立的前缀函数路。

## 问题

文本一长，逐位比较的次数就随位置数与模式长度成倍上涨，平方量级；同一个
起始位置反复比较的公共前缀信息完全没被复用；想问两路互相印证也缺独立入口。

## 目标

在当前基础上补出线性 Z 函数、基于 Z 函数的扩展 KMP 出现位置、独立的前缀
函数路与比较次数对照，见任务描述。约束：

- 现有行为与 tests/test_naive.py 基线保持一致（基线一个字不改）
- 纯标准库
- 两路（裸 Z 与扩展 KMP）结果逐项一致，并与朴素逐位比较一致
