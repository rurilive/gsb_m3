# offx

序列上的离线区间查询，纯标准库，无外部依赖。

## 现状

`offx/batch.py` 提供一份朴素离线批处理层 `QueryBatch`：

- `QueryBatch(values)`：持有一份元素序列，构造时深拷贝，之后序列不再变动
- `range_sum(left, right)`：闭区间元素和
- `range_distinct(left, right)`：闭区间不同元素个数
- `range_count_class(left, right, klass)`：闭区间内等于指定类的元素个数
- `answer_queries(values, queries, mode)`：对一批查询逐条重扫，答案与输入同序
- `scan_visits(queries)`：按逐查询重扫口径估算总访问位置数
- `scan_count` / `reset_scan_count()`：逐元素重扫的总次数，可归零

## 问题

每一条查询都现场从头扫描它自己的那一段，逐位置累加或取极值，查询之间完全独立：
既没有把查询按端点排序，也没有把上一条的结果复用到下一条。查询一多、区间一长，
总代价就是查询条数乘以区间长度，没有任何近线性对数的余地，也没有任何可以证明
增量复用生效的计数出口。

## 目标

在当前基础上补出以离线排序、增量结构与分块为核心的查询工具集：把查询按右端点
排序后配合树状数组逐个把元素加入并回答，再用莫队或分块按左右端点分块排序移动
指针增量维护答案，两条路对同一批查询逐项一致且与暴力口径一致，并暴露指针移动
次数与逐查询重扫次数的差距，见任务描述。约束：

- 现有行为与 `tests/test_batch.py` 基线保持一致（基线一个字不改）
- 纯标准库，Python 3.10+
- 新老两条路径对同一批数据事实逐项一致，异常统一继承一个基类，确定性可复现
