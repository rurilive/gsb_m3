# xorlib

一个纯标准库的小工具: 用朴素方式维护一个整数集合, 并回答和异或相关的问题。

## 现状

`FlatXor` 内部只有一个整数列表。加入就是把元素追加进列表; 与给定值异或最大、
异或最小都是从头到尾线性扫描; 不大于给定值的计数同样线性扫描; 两两异或最大
则是枚举全部元素对, 平方级。每次查询都要扫全表。

## 问题

查询代价绑死在元素个数上。元素一多, 每次异或极值都是在做无用功, 数对异或最大
更是随元素个数平方增长。集合还只能加不能删, 也拿不出恰好等于给定值的计数。

## 目标

把 `FlatXor` 从线性扫描扩成以按位字典树为核心的异或极值工具: 异或极值按位宽
走对数级、数对异或最大不再平方枚举、支持按位计数与删除, 并用计数把访问节点数
与线性扫描的元素数摆在一起量出差距。基线那条线性路径保留, 两条路给出的事实要
对得上。详见需求描述。
