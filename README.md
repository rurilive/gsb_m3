# palindromex

一个只用 Python 标准库的回文工具小包。

## 现状

核心是 pal 模块里的 BrutePal，内部持有一份字符串。判断某段是不是回文，就逐字符从两端往中间比；求最长回文，就枚举每一个子串逐个判断取最长；统计回文子串个数，也把每一个子串都判一遍；对给定中心求最长回文半径，同样向两边暴力扩展。

## 问题

这套做法整体是平方级的。文本一长，枚举子串的判断次数按长度平方增长，很快撑不住。判断回文本身虽然是线性的，但乘以子串的规模之后，整体代价随长度迅速膨胀。

## 目标

把 BrutePal 改造成以回文自动机或等价线性回文结构为核心的字符串工具，仍然只用标准库。最长回文、回文半径数组、本质不同回文子串个数、回文子串总数、全部不同回文、每个回文的出现次数都要线性或近线性求出，且与现有那套暴力枚举所给出的事实逐项对得上。基线那套枚举子串的路径保留下来做对照。

## 运行

在仓库目录下：

```
python3 demo.py
python3 -m unittest discover -s tests
```
