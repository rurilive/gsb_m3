# rbdsu

支持合并、连通判定、集合大小与整体回滚的朴素并查集，纯标准库，无外部依赖。

## 现状

rbdsu/districts.py提供RollbackDSU：

- 构造可给元素个数与可选标签，标签是非空字符串，不给时用编号字符串
- union(a, b)把两个元素所在集合合到一起，已同集合按无操作处理
- connected(a, b)判断两元素是否连通
- size(elem)给出元素所在集合的成员个数
- members(elem)给出集合成员名列表的副本，groups()给出全部集合
- checkout()打一个整数时间点，rollback(point)回滚到该时间点

## 问题

每个集合把成员逐个放进一张列表，合并时固定把一方的成员逐个搬进另一方，
回滚时把整张成员表从父指针关系从头重算一遍。没有历史栈，合并与回滚都要
把成员搬来搬去，集合一大、操作一多，代价迅速退到平方甚至更高量级。
