# hashx

字符串子串判等与常见子串问题的朴素工具，纯标准库，无外部依赖。

## 现状

hashx/strings.py 提供 StringTools：

- StringTools(text="")：收下一条文本，非字符串立刻报错
- text()：取回文本本身
- equal(a_start, a_end, b_start, b_end)：判断同一文本中两个子串是否相等
- longest_repeat()：最长重复子串（至少出现两次），取最早出现的一例
- longest_palindrome()：最长回文子串，取最早出现的一例
- longest_common_substring(other)：与另一文本的最长公共子串，取最早出现的一例

内部判等一律逐字符比；求最长重复子串、最长回文、最长公共子串都是先枚举出
全部子串（或子串对），再逐个字符比较，规模一大就是立方或平方级。
结果正确，速度不快，也没有任何可复用的哈希与幂表。

## 问题

每判一次子串相等就要从头逐字符扫一遍，最坏情况下字符重复度高时退化明显；
求最长重复子串与最长公共子串都把全部子串对枚举出来再逐个比，长文本下
代价随长度立方增长；最长回文也是把每个子串切片反转后整体比较，白白复制
大量字符；两条路径之间没有一套可以常数级取出任意子串指纹的机制可比。
