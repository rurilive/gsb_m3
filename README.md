# walg

账本服务的单机预写日志，纯标准库。

- `walg/wal.py`：`WriteAheadLog.append()` 追加记录并同步刷盘，`read_from()` 按 LSN 重放
- `tests/test_wal.py`：行为与磁盘格式基线
- `demo.py`：顺序写入演示

## 组提交设计

- `append()` 把记录排进内存队列就阻塞等待，由后台刷盘线程统一落盘。
- 一批凑满 256 条或 1MB 立即切批；只有上一批打满（高峰期）才多等 2ms 攒批。
- 低负载来一条刷一条，延迟约等于一次 fsync，不为凑批拖响应。
- 每批一次 `write` + 一次 `fsync`，完成后整批一起被唤醒返回。
- `append` 返回即落盘的语义不变：应答前该记录所在批必须 fsync 成功。
- 刷盘失败：批内及之后所有 `append` 抛同一个 `OSError`，WAL 进入不可用状态。
- 刷盘途中进程被杀：重启时截掉末尾残记录，已应答的记录不会丢。
- 记录按 LSN 顺序入队、顺序写盘，重放顺序与写入顺序一致。
