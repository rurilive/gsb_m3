# blockx

一个只用 Python 标准库的小仓库，提供可变序列上的区间操作工具集。

## 现状

- 包名 `blockx`，核心类 `Seq`，位于 `blockx/seq.py`。
- 内部只有一份平铺的 list，元素按构造给出的顺序保存，允许负数。
- `sum(left, right)` 逐个累加半开区间 `[left, right)` 内的元素，空区间返回 0。
- `add(left, right, delta)` 用循环对区间内的每个元素逐个改写。
- `min_val` / `max_val` 逐个比较出区间最值，空区间抛 `EmptySequenceError`。
- `get(index)` / `set(index, value)` 按下标读改单点，越界抛 `IndexOutOfRangeError`。
- `replay(values, operations)` 在副本上依次回放一串操作，返回末态与逐步返回值。
- 所有自定义异常继承自 `BlockxError`。

## 问题

每次区间求和、区间加或者区间最值都要把整段从头扫一遍，单点读改虽然
是常数量级，但改完之后没有任何聚合量可以复用。规模一上来，每个区间
操作的代价就随区间长度线性上涨，序列里也没有任何分块或层级结构。

## 目标

把核心从平铺列表换成以分块（根号分治）为核心的序列工具集：把序列切成
若干个大小约为根号长度的块，每块维护聚合量（和与最值）以及整块的惰性
标记；区间操作时整块直接读标记与聚合量、散块暴力重算，做到区间修改与
区间查询均为根号量级；支持单点查询与单点修改；支持区间求和、区间加、
区间赋值与区间最值；对外暴露块数与被访问元素计数，把分块路径与朴素
重扫路径的访问量差距量出来。改造后分块路径与朴素路径对同一批数据给出
的事实必须逐项一致，原先那套朴素列表操作保留下来做对照。
