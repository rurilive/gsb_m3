# digitx

一个只用 Python 标准库的数位计数小工具。包内模块 count.py 提供 BruteDigits 类，
围绕从一到某个上界 n 的整数做四类计数：count_with_digit 统计十进制里含某个
数字的整数个数，sum_of_digits 求全部整数各位数字之和，count_less_than 统计数值
不大于给定上界的整数个数，count_divisible 统计能被 m 整除的整数个数。

## 现状

BruteDigits 的计数一律靠逐个整数枚举：从一到上界一个不落地走一遍，把每个整数
翻成十进制串再逐位检查，含某数字就计数、各位求和、比较大小、判断整除。规模小
时直观可靠，结果也一目了然。

## 问题

逐个枚举的计算量随上界线性增长，上界一大就线性退化。当前实现既没有把状态同
位数挂钩，也没有任何手段把走过的状态数量出来，无法说明一条更聪明的做法到底省
了多少，更谈不上处理数位单调、数位互异这类跨位约束的计数。

## 目标

把 BruteDigits 从逐个枚举扩成以数位动态规划为核心的计数工具：按十进制位从高位
到低位推进，用状态记录是否已贴合上界、是否已出现某个数字，逐位转移完成各类计数；
含某数字计数、数位和、不大于给定值的计数、整除计数都要与逐个暴力一致，整除计数
用余数作状态；再由数位动态规划统计数位不降与各数位互异的整数个数；暴露状态计数，
用量出的状态数证明它只与位数有关而与上界大小无关；覆盖上界为零、单数位、全为九、
含零的数字、负上界等边界；固定参数重复跑两次结果完全一致；异常统一继承 DigitError
基类并快速失败；基线那套逐个枚举路径不许删，两条路对同一批数据的事实必须对得上。
