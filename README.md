# rangeidx

内存表的二级有序索引，纯标准库，无外部依赖。

## 现状

`rangeidx/table.py` 提供一张具名行式内存表 `Table`：

- `Table(name, pk="id", fields=None)`：行以字典存放，主键缺省为 `id` 字段
- `insert(record)`：追加一条记录，返回落库后的副本
- `scan(predicate)`：线性扫描，对每一条记录判断谓词，返回命中记录的副本列表，保持插入顺序
- `count()` / `fields` / `all()`：行数、按出现顺序的字段名、全部记录的副本
- `access_count` / `reset_access_count()`：查询逐条走过的记录数，可归零

## 问题

只有一层朴素过滤：任何查询都要把整张表走一遍，访问计数等于表的行数。
等值、范围、前缀这些常见谓词一个索引都没有，字段一多表一大就全是全表扫描，
查询到底走没走索引无从证明。

## 目标

在当前基础上补出按字段建的二级有序索引、范围查询、前缀查询，并支持增删改
同步维护索引与唯一约束，见任务描述。约束：

- 现有行为与 `tests/test_scan.py` 基线保持一致（基线一个字不改）
- 纯标准库，Python 3.10+
- 不许把范围与前缀查询做成换皮的全表扫描，必须能给出走索引的证据
