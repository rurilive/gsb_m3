# bitpackx

正整数集合的朴素子集和工具，纯标准库，无外部依赖。

## 现状

bitpackx/subset.py 提供 BitBag：

- BitBag(items=())：把若干正整数收成一个集合，非整数、负数与零立刻报错
- add(value)：追加一个正整数，返回自身以便链式调用
- items()：取回元素列表，对外只读
- reachable(target)：目标和能否由若干元素凑出
- reachable_set(limit)：不超过上限的全部可行和，升序列表
- count(limit)：不超过上限的可行和个数
- max2(limit)：不超过上限的最大可行和，凑不出时返回 None

内部用布尔数组记录可达和，每加一个数就把当前可达区间整个扫一遍逐格扩展，
规模一大就是平方级，但结果正确。

## 问题

表达可达和集合的只有一条条布尔格子，每次扩展都要把已可达的部分逐个取出来
再加一遍，元素一多、上限一大就明显变慢；上限多高就要开多长的数组，稀疏的
基础形态下大量格子空着；数的出现次数也无法约束，多重背包这类要求根本没法
表达；两条路径之间也没有整体位移这种把整批可达和一次推进的办法可比。
