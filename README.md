# sortx

一个只用 Python 标准库的小仓库，提供线性时间排序族的排序工具集。

## 现状

- 包名 `sortx`，核心模块 `sortx/sortkit.py`。
- `integer_sort` 把一串整数排成升序，直接调用内置的全排序。
- `nonnegative_sort` 先遍历一遍确认没有负数，再交给内置全排序。
- `fixed_sort` 按给定小数位把数放大成整数，内置排序之后再缩回去。
- `key_sort` 先把自定义键算出来，再交给内置排序。
- `sort_and_assert_stable` 给出排序结果，并靠原始下标核对稳定判据。
- `count_max` / `count_min` 遍历一遍求取值上下限，空序列返回零。
- `compare_with_builtin` 把本包结果与内置排序逐项比对。
- `probe_kernel` 在模块级留了一份可变状态，重复调用结果会变。
- 所有自定义异常继承自 `SortxError`。

## 问题

眼下所有排序都只是把结果托付给内置的全排序，包内并没有真正的计数、基数
或者分桶过程。稳定是在排序之外另靠一列下标核对出来的，取值上限靠一遍又
一遍遍历去数，比较次数或者分配次数根本量不出来。于是既看不出线性排序不
做元素间比较这一事实，也没法按值域建表、按位逐轮推进或者按桶分堆之后再
拼接；一旦要支持定点数、按字段排序与自定义键，口径就只能各写一套。

## 目标

把核心扩成一套以计数排序、基数排序与桶排序为核心的线性时间排序工具集：
计数排序按值域建计数表、再做前缀和定位；基数排序按低位到高位逐轮稳定
排序；桶排序把值域划成若干桶、桶内排序之后再拼接。要求把稳定排序的口径
写清并断言，要求排序结果与内置全排序逐项一致，要求暴露比较次数或者分配
计数，量出线性排序不做元素间比较这一事实；支持整数、非负整数与带固定
小数位的定点数中的若干项，并可选支持按某字段排序与自定义键。改造后新老
两条路径对同一批数据给出的事实必须逐项一致，原先那套朴素实现保留下来做
对照。
