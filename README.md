# ternsearch

纯标准库的离散点极值工具雏形，无外部依赖。

## 现状

ternsearch/extremum.py 提供 PeakFinder 与 DiscreteSequence：

- minimize、maximize：在闭区间 [lo, hi] 上枚举每个整数点求最小值、最大值，返回位置与值
- peak_position：枚举求峰值位置，函数值并列时取最左的下标
- convex_minimum：把二次函数在区间上枚举一遍求最小值，二次项为负报错
- integer_maximum：整数定义域上求最大值的另一个入口
- sequence_peak：把离散数据当单峰序列，逐下标枚举求峰值位置
- eval_count：跑一遍枚举求最小值，返回这次枚举算了多少下

底层只有一条路，逐点算函数值，边扫边记最优。求值次数正比于定义域大小，
区间一大就要从头算到尾。

## 问题

定义域是一百万个整数点就要求一百万次函数值，慢得没有道理；单峰与凸性
明明能让每一步砍掉一大段区间，现在一点都没用上。求峰值位置、求凸函数
最值、求离散序列峰值，各写各的循环，口径分散在多处，容易对不齐。

## 目标

在当前基础上补出三分法求极值、两条独立印证路、单峰判定与求值次数对照，
见任务描述。约束：

- 现有行为与 tests/test_extremum.py 基线保持一致（基线一个字不改）
- 纯标准库
- 新老路径对同一批数据给出的事实必须逐项一致
