# intervalx

区间集合工具，纯标准库，无外部依赖。

## 现状

`intervalx/tree.py` 提供 `FlatIntervals`，维护一组半开区间 `[l, r)`，每个区间带一个标识：

- `add(l, r, name)`：加入一条区间，同名标识覆盖旧值
- `overlaps(l, r)`：返回与给定区间相交的全部标识
- `point_hit(x)`：返回覆盖点 `x` 的全部标识
- `remove(name)`：按标识移除，删到返回 True
- `merge_all()`：合并全部区间，返回不相交的区间列表
- `names()` / `intervals()` / `__len__` / `__contains__`

端点口径是左闭右开：`x` 命中当且仅当 `l <= x < r`；仅端点相接不算相交；
`l == r` 的退化区间是空点集；合并时重叠与相接的区间并成一段。

## 问题

每次相交查询与点命中都逐条扫描全部区间，是 O(n)。区间一多，绝大多数扫描都是白扫：
查询只和少数区间有关，却把整个集合走了一遍。删除后也没有任何索引可依赖，只能靠全量扫描维持正确性。

## 目标

把 `FlatIntervals` 从线性扫描扩成以区间树（或线段树、平衡树）为核心的区间索引：
以左端点为键建平衡树，每个节点维护子树内最大右端点用于剪枝，相交查询据此跳过整个不相关的子树，
点命中、删除、全合并与覆盖长度并集都要与线性暴力逐项一致，并用访问节点计数把索引与暴力扫描的差距量出来。

约束：

- 现有行为与 `tests/test_tree.py` 基线保持一致（基线一个字不改，必须全绿）
- 新行为另开 `tests/test_interval_tree.py`
- 纯标准库
