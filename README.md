# multimatch

一个极简的纯标准库多模式匹配包，Python 3.10+，无外部依赖。

## 现状

`multimatch/find.py` 只提供最朴素的逐模式扫描匹配器 `EachPattern`：模式集
在构造时记成一个按注册顺序排列的元组，查找时对每个模式各自跑一遍朴素子串
查找，再把结果按模式注册顺序拼起来。没有前缀树，没有失配指针，没有共享
前缀，也没有一次遍历——文本因此会被反复扫描多遍。

- `EachPattern(patterns)`：构造匹配器，模式必须是字符串且不能为空串
- `EachPattern.patterns()`：按注册顺序列出全部模式
- `EachPattern.find(text)`：逐模式扫描文本，返回全部 `Match(pattern, start, end)`，
  结果按模式注册顺序分组，同一模式内部按下标升序，重叠出现都会被报出

允许空的模式集，此时匹配器不命中任何东西。模式不是字符串、模式为空串、文本
不是字符串，一律快速失败并抛出 `InvalidPatternError`。

## 目标（见任务描述）

字典树：把全部模式构成前缀树，共享公共前缀，节点数与边数符合前缀共享口径。

失配指针：为每个节点算失配指针，指向最长真后缀所在节点，失败转移不退回根重扫，
匹配时文本只遍历一次。

输出集合：节点带输出集合，命中某模式时同时输出它沿失配链继承的更短模式，重叠
模式（互为子串）都要报出，与逐模式扫描口径逐项一致。

扫描：一次遍历文本报出全部出现，输出含模式与起止下标，重叠出现不漏，结果顺序
按确定规则稳定。

动态增删模式：支持在已建好的自动机上增删模式并维护失配与输出，增删后匹配结果
与重建口径一致。

边界：空模式集、空文本、模式为空串、单字符字母表都正确；非法模式集 fail fast。

约束：

- 基线测试 `tests/test_find.py` 一字不改，且必须保持全绿
- 新行为另开测试文件 `tests/test_automaton.py`，用固定模式集与文本断言
- 纯标准库，不引入任何第三方依赖
- 自定义异常继承 `MultiMatchError` 基类

## 运行

