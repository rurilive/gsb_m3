# bmsearch

字符串查找的朴素工具，纯标准库，无外部依赖。

## 现状

bmsearch/search.py 提供 BmSearch：

- BmSearch(pattern="")：收下模式串，非字符串立刻报错
- pattern()：取回模式本身
- find_occurrences(text)：模式在文本中全部出现位置的起始下标，升序且允许重叠
- count_occurrences(text)：出现位置个数
- contains(text)：是否至少出现一次
- match_steps()：最近一次查找的逐次匹配信息（起始下标、位移次数、比较次数）
- search_steps()：最近一次查找的字符比较总次数
- search_jumps()：最近一次查找的窗口位移总次数
- naive_comparisons(text)：对给定文本走一遍朴素查找，返回其字符比较总次数

对文本的每个对齐位置从前往后逐字符比对，一旦失配就把窗口整体右移一位、换文本的
下一个起点重新对齐比较。找出现位置、统计出现次数、判断是否出现，全都走这一条
逐位对齐的路子，位移量恒为一，没有任何根据坏字符或已匹配后缀跳过一段的机制。
规模一大就是平方量级，字符大量重复时退化明显，结果正确，速度不快。

## 问题

只按一位一位右移重来，失配时提供的位移信息全被丢掉，长文本上比较次数与位移
次数都随长度迅速增长；没有坏字符规则表，也没有好后缀规则表，更谈不上两条启发式
取较大位移量；缺少一条与前缀函数互相印证、独立求出现位置的对照路径。
