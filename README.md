# fuzzyidx

词条倒排索引，纯标准库，无外部依赖。

## 现状

`fuzzyidx/index.py` 提供 `FuzzyIndex`：

- `add_doc(doc_id, terms)`：登记一份文档及其词表，同名文档重复登记按覆盖处理，返回最终登记的词数
- `remove_doc(doc_id)`：注销一份文档，返回是否真的删掉了
- `doc_count()` / `term_count()`：已登记文档数、词表里不同词的个数
- `terms()`：按字典序返回词表副本
- `docs_for(term)`：精确整词匹配，返回命中的文档集合
- `doc_terms(doc_id)`：一份文档登记过的词，按字典序
- `access_count` / `reset_access_count()`：查询逐条走过的倒排项数，可归零

## 问题

匹配只有精确整词这一种，而且还是靠线性扫描糊出来的：每查一次都要把当前
词表整个过一遍，访问计数等于词表大小，跟命中多少无关。没有真正的倒排表，
前缀查询与编辑距离模糊查询都没有入口，删除之后词表里留下的空洞也无从清理。

## 目标

在当前基础上补出倒排表增量维护、支持编辑距离与前缀的倒排模糊检索，见任务描述。约束：

- 现有行为与 `tests/test_index.py` 基线保持一致（基线一个字不改）
- 纯标准库，Python 3.10+
- 模糊检索不许对全体词逐条跑完整编辑距离，必须能给出剪枝的证据

## 运行

```bash
python3 demo.py
python3 -m unittest discover -s tests -v
```
