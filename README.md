# weightsem

纯标准库的计数器与许可控制雏形，无外部依赖。

## 现状

weightsem/semaphore.py 提供一把普通计数信号量：

- Semaphore(capacity)：一个许可总数，非正整数立刻报错
- acquire、release：一次取一个、还一个许可，不排队、不区分持有者
- available、held、capacity：当前可用、已持有与总数
- 取空之后还取会抛 SemaphoreBusy，还满之后再还会被拒绝

## 问题

它只会一次一个地吞吐许可，谁先要谁后要没有先后，许可要得多的请求没法
一次拿到；不会等待，也没有超时；同一个持有者想多拿几个许可只能当成好几个
互不相识的请求，释放时也分不清该还几个；容量定死之后增减不了，遇到需要
临时收紧的场景只好整把换掉；可用、已持有、等待者这几个数各算各的，对不上。

## 目标

在当前基础上补出加权获取、可超时、公平排队、可重入、动态缩容与统计自洽，
见任务描述。约束：

- 现有行为与 tests/test_sem.py 基线保持一致（基线一个字不改）
- 纯标准库，Python 3.10 以上
- 并发之下已持有加已用绝不超过容量
