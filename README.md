# minplus

一个只用 Python 标准库的最小加矩阵与递推工具包。包内模块 minplus.py 提供
MatPlusKit 类与几个独立函数，围绕有向带权图与最小加代数做最基础的几件事：
shortest_paths 求恰好若干步的最短路，step_transitions 按边逐步推状态向量，
matrix_power 做最小加矩阵的幂，另配 mat_mul 做一次最小加矩阵乘法。

## 现状

固定步数最短路做成一张距离表，每推进一步就把整张表重新扫一遍做重复松弛，步数
多大就扫多少遍；定步数状态转移每推一步就按边逐项枚举取最小加，推一步整条向量
重扫一遍；矩阵幂把同一个矩阵连乘指数那么多遍，指数多大就要做多少次矩阵乘法，
每次乘法又是立方量级的三重循环。无穷大用 math.inf 表示，不可达点在结果里保持
无穷。规模小时直观可靠，结果一眼能看穿。

## 问题

步数或指数一旦变大，逐遍重扫就是线性量级乘以立方量级，顶不住；实现既没有把
步数从线性压到对数的手段，也没有把新老两路的结果摆在一起逐项核对，更没有一条
独立的对照做法来给快速路径把关，步数为零、含零权边、不可达点、自环这些边界
只能靠肉眼去猜。

## 目标

把 MatPlusKit 从朴素重扫扩成一套最小加快速求值工具集：把每步的转移矩阵按最小加
乘法做二分幂，把固定步数最短路与定步数递推降到对数级；另起一条独立做法在固定
输入上与快速路径逐项一致；覆盖不可达点、对角线为零、含零权边、步数为零、步数为
一、自环等边界；异常统一继承 MinPlusErro 基类并快速失败；基线那条朴素路径一条都
不许删。
