# splayx

一个只用 Python 标准库的小仓库，提供"有序多重集合"。

## 现状

- 包名 `splayx`，核心类 `SortedBag`，位于 `splayx/btree.py`。
- 内部只有一个始终保持升序的 list，允许重复值。
- `insert` 用二分找位置后插入，`remove` 二分定位后删除；
  两者都要用列表切片在中间搬动元素，代价随元素个数线性增长。
- `find` 返回等价元素或 `None`。
- `kth` 返回第 i 小（零基），越界抛 `BagError`。
- `rank` 返回严格小于给定值的元素个数。
- `predecessor` / `successor` 返回严格前驱与严格后继，不存在返回 `None`。
- `count_range` 返回闭区间内的元素个数。
- `inorder` 返回中序遍历结果（朴素实现下即升序拷贝）。
- 所有自定义异常继承自 `BagError`。

## 问题

每次中间插入或删除都要搬动一整个数组；前驱后继与按排名取值都退化成
排序或线性扫描，没有任何可以复用的树状层级。规模一大，局部改动的
代价就随元素个数线性上涨。

## 目标

把核心从有序数组换成以伸展树（带子树大小的有序统计树）为核心的工具集：
实现单旋与双旋（一字型与之字形）两种旋转，任意访问后把节点伸展到根以
摊还平衡；在保持现有口径不变的前提下，支持插入、删除、查找、前驱、后继、
第 k 小、求排名，并支持按位置切分合并两棵树，从而支持区间翻转、区间加等
带懒标记的区间操作，同时保证中序遍历始终有序。新老两条路径对同一批数据
给出的事实必须逐项一致，原先那套朴素数组操作保留下来做对照。
