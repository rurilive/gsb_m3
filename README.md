# trievocab

一个纯标准库的字符串词表工具: 维护一批字符串, 回答前缀相关的统计问题。

## 现状

`trievocab/vocab.py` 提供 `FlatVocab`, 内部只有一个字符串列表。插入就是把字符串
追加进列表, 删除是按值从头找位置再挪走; 存在性判定逐个字符串做整串逐字符相等比较,
前缀判定与前缀计数都拿前缀对每个字符串从头逐字符比较, 按前缀取全部字符串与取去重
集合都靠扫全表后再排序, 按字典序输出靠排序, 最长公共前缀逐列比较全部字符串。
`compare_count` 记录查询逐字符比较实际走过的步数, 并能归零。

## 问题

每次查询都要把整份词表从头扫一遍。词表一多, 前缀判定、前缀计数与去重前缀集合都要
对每个字符串从头比较一次, 明明只与前缀那几个字符有关, 绝大部分比较都是白做的;
`compare_count` 等于词表大小乘前缀长度, 跟真正命中多少毫无关系。删除要线性找位,
删完之后也没有任何层级结构让后续查询变快, 没有字典树, 前缀的公共部分无从复用。

## 目标

把 `FlatVocab` 从线性扫描扩成以字典树为核心的词表: 逐字符插入与删除, 路径上维护
前缀计数与单词结尾计数, 支持前缀判定、按前缀计数、完整单词判定、按前缀取全部字符串
与去重集合、按字典序输出、最长公共前缀, 另补通配符匹配与删除后的计数回退。基线那条
线性路径保留, 两条路给出的事实要对得上。详见任务描述。
