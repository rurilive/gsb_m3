# histkit

纯标准库的撤销记录小包雏形，无外部依赖。

## 现状

histkit/recorder.py 提供最简单的线性撤销记录器 HistRecorder：

- 构造时给一个初始状态，内部用一条列表 _states 顺序保存状态快照
- push：把一份新状态追加到列表末位，成为当前状态
- undo：退回上一份状态，已经在最初状态时返回当前状态
- state 与 depth 分别报告当前状态与已记录的状态份数

它只能沿一个方向退，退过之后没有反方向的 redo，也没有任何分组、
合并与容量的概念。

## 目标（见任务描述）

把它从一个线性快照记录器扩成一套完整的命令历史系统，仍然全部放在
histkit 里，纯标准库。要补出命令模式的 undo 与 redo、redo 在被新变更
打断后清空、连续同类命令的合并与可回放、命令组或事务的原子提交与整体
回滚、有限历史按策略淘汰最旧、以及可撤销与可重做步数的报告和历史跳转
重放，见任务描述。
