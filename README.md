# nearbex

一个纯标准库的 Python 文本相似度工具包。

## 现状

当前只提供最朴素的逐字符比较：`CharDiff` 把两个字符串按位置对齐，
数出字符不同的位置个数作为差异数。没有特征指纹，没有哈希，
没有海明距离，也没有任何近似检索能力。

## 目标（见任务描述）

把 nearbex 从逐字符比较扩成近似相似检索，提供固定哈希种子下的特征指纹、
指纹间的海明距离与相似度、分段索引的近似近邻检索、按指纹聚类去重，
以及空文本与非法参数的明确口径，全部仍在 nearbex 包内，纯标准库实现。

## 运行

```
python3 demo.py
python3 -m unittest discover -s tests -v
```
