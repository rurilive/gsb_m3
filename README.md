# graycode

纯标准库的位序列工具雏形，无外部依赖。

## 现状

graycode/naive.py 提供几条朴素能力：

- gray_sequence：生成给定位数的格雷码序列，从全零串出发，每一步对每一位
  依次试翻，挑一个没用过又只差一位的串往下走，走不通就回退重挑
- is_gray_sequence、diff_count：判断一条序列是不是合法格雷码（含首尾回环）、
  两个等长位串相差几位，靠逐个对比
- gray_index：求某个位串在序列里的位置，靠造出整条序列再逐个比对
- subsets_in_bit_order、subsets_in_gray_order：按二进制计数顺序枚举集合
  的全部子集，后者借试凑出的格雷码顺序，并给出每步增删的元素下标
- GrayTools：绑定一个位数，方法同上并累计试探候选串的次数，可读取与清零

所有结果都对，但生成序列靠反复试凑加深搜回退，规模一大次数就随位数疯涨，
也没有直达公式、递归镜像或逐位翻转的线性做法。

## 问题

位数一增加，试凑的候选串就成倍增长，指数级往上蹿；同一个位串的位置、整条
序列的合法性都靠把序列重新造一遍再线性扫描，前面算过的信息一点没被复用；
想在多条独立做法之间互相印证也缺入口。

## 目标

在当前基础上补出公式法、递归镜像法、逐位翻转法三条独立生成路，逆运算、定
位、合法性判定，以及基于格雷码顺序的子集枚举与规模对照，见任务描述。约束：

- 现有行为与 tests/test_naive.py 基线保持一致（基线一个字不改）
- 纯标准库
- 三条生成路与旧的朴素试凑结果逐项一致，子集枚举与按位序枚举逐项一致
