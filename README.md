# digitcount

一个只用 Python 标准库的区间数位计数小工具。包内模块 counter.py 提供
NaiveDigitCounter 类，围绕闭区间 [lo, hi] 里的全部非负整数做四类计数：
count_sum_mod 统计各位数字之和对某模取余等于某值的整数个数，count_contains
统计十进制表示里含某个数字的整数个数，count_monotonic 统计数位从左到右不下降
的整数个数，count_palindrome 统计十进制表示是回文的整数个数。

## 现状

四类计数一律靠逐个整数枚举：把闭区间里每个整数一个不落地走一遍，翻成十进制串
后逐位分解，再逐条判定。区间窄的时候直观可靠，结果也一目了然。

## 问题

逐个枚举的计算量随区间宽度线性增长，区间一大就线性退化，数位条件稍复杂还要在
每个整数上反复重算同样的前缀。当前实现既没有按位从高位到低位推进的状态结构，
也没有任何手段把走过的状态数量出来，无法说明一条更聪明的做法到底省了多少，更
谈不上把多个数位条件组合起来、用端点相减的口径做区间计数。

## 目标

把 NaiveDigitCounter 从逐个枚举扩成以数位动态规划为核心的区间计数工具：按十进制
位从高位到低位逐位确定，对每个自由位做记忆化，用状态记录是否已贴合上界、各位
数字和、相邻数位关系、已出现数字集合、回文配对进度等维度，逐位转移完成各位数字
之和的模、相邻数位关系、是否含某数字、回文数位等条件的区间计数；整体支持下界与
上界两个端点相减的口径，新老两路对同一批区间逐项一致；暴露记忆状态命中与逐位
枚举的次数差，说明它与位数有关而与区间大小无关；覆盖上界为零、区间退化成一个点、
前导零处理、全位固定等边界；固定输入重复跑结果一致且不依赖模块级可变状态；异常
统一继承 DigitCountError 基类并快速失败；基线那套逐个枚举路径不许删。
