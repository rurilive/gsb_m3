# suflcp

纯标准库的后缀数组与最长公共前缀雏形，无外部依赖。

## 现状

suflcp/engine.py 只提供最朴素的两条路：

- naive_suffix_array：把文本的所有后缀起点取出来，按整段后缀切片做字典序
  排序，排序键就是从起点切到末尾的整段切片，比较时从头逐字符看
- naive_lcp_array：相邻后缀的最长公共前缀逐对现算，每对都从头重新扫描
- common_prefix_len：任意两后缀的最长公共前缀，同样是逐字符现算
- SuffixArray：把上述结果封成一个门面，另有 rank 排名逆表

## 问题

排序每次比较都要重新切出整段后缀再逐字符比，规模一大就是平方以上量级；
相邻前缀每条都从头重新扫，最坏情况下大量重复劳动；任意两后缀的查询没有
任何索引支撑，只能一次次现算。

## 目标

在当前基础上补出倍增法后缀数组、卡萨伊线性扫描的相邻最长公共前缀、区间
最小值支撑的任意两后缀查询，并另起一条独立做法在固定输入上逐项对拍，见
任务描述。约束：

- 现有行为与 tests/test_engine.py 基线保持一致（基线一个字不改）
- 纯标准库
- 新老两条路对同一批输入给出的事实必须逐项一致，异常统一继承 Erro 基类
