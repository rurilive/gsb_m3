# triex

一个纯标准库的小工具: 用朴素方式维护一个可重复、可增删的整数集合, 并回答和
异或相关的问题。

## 现状

`FlatXor` 内部只有一个整数列表。加入就是把元素追加进列表, 删除就是按值从列表
里挪走一个; 与给定值异或最大、异或最小都是从头到尾线性扫描; 两两异或最大则是
枚举全部元素对, 平方级。每次查询都要扫全表。

## 问题

查询代价绑死在元素个数上。元素一多, 每次异或极值都是在做无用功, 数对异或最大
更是随元素个数平方增长。集合现在能加也能删, 但每次删除都要线性找位, 删完之后
也没有任何结构让后续查询变快。

## 目标

把 `FlatXor` 从线性扫描扩成以二进制字典树为核心的异或最值工具: 整数按固定位宽
从高位到低位插入字典树, 每个节点带子树计数以支持删除; 与给定值异或最大时贪心
按位反向走, 异或最小则同向走; 数对异或最大不再平方枚举, 而是把每个数在树里
贪心找最优配对; 集合可增可删可重复, 删除要正确维护路径计数。基线那条线性路径
保留, 两条路给出的事实要对得上。详见需求描述。

## 运行

```
python3 demo.py
python3 -m unittest discover -s tests
```
