# shortestpath

一个只用 Python 标准库的带非负权图单源最短路工具包。包内模块 dijkstra.py 提供
NaiveGraph 类：用一串三元组建图，distances 求从源点到各可达点的最短距离，
paths 与 path 回溯拼出路径，unreachable 列出不可达点，lookups 量出求解时在
未确定集合里线性比较的次数，nodes 与 stats 看结点与访问量快照。

## 现状

求解时每轮在尚未确定的结点里从头线性扫描一遍找出距离最小者，把它确定下来，
再逐边把它的邻居松驰一遍；如此往复直到没有可确定的结点。路径靠逐段记住前驱
再回溯拼出。规模小时结果一眼能看穿，也从来没有出过错。

## 问题

一轮找最小就把还没确定的结点全部走了一遍，轮数又随结点数增长，单次求解的
代价随结点数平方增长：连通图里一共要比 n 加 n 减一一直加到一，也就是二分之一
n 乘 n 加一。既没有以二叉堆维护候选距离的结构，也没有暴露线性找最小与堆取最小
访问次数差距的出口，规模一上来既跑不动也量不出真实开销。

## 目标

把 NaiveGraph 从每轮线性找最小扩成以二叉堆维护候选距离的近似对数级实现，据
松驰结果重建从源点到各点的路径并统计不可达点的处理，要求新老两路对同一批图
的距离数组与路径逐项一致，暴露线性找最小与堆取最小的访问次数差距，覆盖源点
自环、平行边、孤点、权为零的边、起点终点相同、不连通等边界，异常统一继承一个
Erro 基类，固定输入重复跑结果一致且不依赖模块级可变状态，并说明不可达点用何
口径表示。
