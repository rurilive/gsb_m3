# ratelib

ratelib 是一个无外部依赖的 Python 限流小库，当前版本只提供一个最朴素的限流原语。

## 现状

包内只有 `CountLimit`，它维护一个只增不减的已用计数：在生命周期内最多放行 limit 次请求，超过之后一律拒绝，只有手动调用 reset 才会清零。它完全不看时间，没有窗口，不会按时间恢复，也没有按键分桶、令牌补充或并发保护。构造时虽然接收一个注入的整数时钟，但基线实现只是把它存下来，从不读取。这个基线行为由 `tests/test_limiter.py` 锁定。

## 问题

固定计数没有时间维度：额度一旦用满就永久拒绝，只能靠人工 reset，既无法表达「每段时间最多几次」，也无法吸收突发流量，更无法在多线程下安全使用。限流库真正需要的是可复用、可组合、行为确定的多策略工具。

## 目标（见任务描述）

把 CountLimit 从固定计数扩展成一套完整的多策略限流工具：固定窗口、滑动窗口、令牌桶、漏桶，外加按键分桶、并发安全、复杂度保证与确定性，全部仍留在 ratelib 包内，且只用标准库、只依赖注入时钟。具体口径见任务描述。
