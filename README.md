# shardcount

一个计数器小工具，纯标准库，无外部依赖。

## 现状

shardcount/counter.py 里只有一个单锁全局计数器 ShardCounter：

- incr(delta=1)：把计数加上 delta，非法步长在入口拒绝
- get()：读出当前的计数
- reset()：清零，回到刚建立时的状态

它把全部读写压在同一把互斥锁上，计数就是一个整数字段。没有分片，
热点全在一把锁上；不看时间，拿不出「最近这段时间涨了多少」这类量；
没有快照与上限，调用方也拿不到一个一次成型的一致读数。

## 问题

单锁全局计数器在高并发下所有 incr 都要抢同一把锁，扩展性差；计数与
时间无关，给不出滑动窗口内的增量，老增量无法随时间失效；没有上限与
原子语义，调用方想「加到这个数就不许再加」得自己在外面加锁；也缺少
一次取全量的一致快照，读到的值可能在更新中途。
