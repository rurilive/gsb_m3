# cdqx

三维偏序计数工具，纯标准库，无外部依赖。

## 现状

`cdqx/core.py` 提供一组朴素但正确的两两比较实现：

- `DominanceCounter(points, weights=None)`：一组带三个属性的点，权值缺省为一
- `DominanceCounter.points`：按登记顺序给出的三元组元组
- `DominanceCounter.weights`：每个点的权值元组
- `DominanceCounter.size`：点的个数
- `counts_weak()`：每点被多少个点在各维都不超过它支配，逐点扫全部点
- `counts_strict()`：每点被多少个点在各维都严格小于它支配，逐点扫全部点
- `pairs_weak()`：全部三维偏序对个数（不超过口径），把每点计数加起来
- `pairs_strict()`：全部三维偏序对个数（严格小于口径），把每点计数加起来
- `order_by_axis(axis)`：按某一维升序给出点下标次序，反复扫描取最小，同值稳定
- `weighted_counts_weak()`：按点权加权的偏序计数，口径为各维都不超过
- `weighted_counts_strict()`：按点权加权的偏序计数，口径为各维都严格小于
- 计数器 `last_naive_comparisons` 与 `last_bit_probe_count`：记录一次调用的
  两两比较点对次数与树状数组访问次数

所有对外异常都继承 `CdqxErro`，固定输入重复调用结果一致，不依赖模块级可变状态。

## 问题

只有一层两两比较：任何一次计数都要对每个点扫全部点，再逐维比对，点数一多
就是平方量级，规模一大就跑不完；按维排序也靠反复扫描取最小，同样是平方量级；
点权加权只是把同样的两两比较再累加一遍；没有任何先排序去重再分治的手段，
也没有规模计数能把朴素比较量与分治路径的树状数组访问量摆在一起对照。

## 目标

在上面的基础上补出 CDQ 分治路径：先按第一维排序去重，递归处理左右两半，
合并时用树状数组按第二维维护第三维的贡献统计，给出每个点的偏序计数与总
的三维偏序对数；再接一个独立做法印证（按第一维排序后对每一对用二维偏序
逐层统计，或按维依次排序归并），以及点权加权的分治计数，并与朴素两两枚举
在小规模数据上逐项一致。见任务描述。约束：

- 现有行为与 `tests/test_core.py` 基线保持一致（基线一个字不改）
- 新行为另开测试文件
- 纯标准库，Python 3.10+

## 运行

```bash
python3 demo.py

```
