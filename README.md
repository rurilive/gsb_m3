# gomoryhu

无向图全体点对最小割工具雏形，纯标准库，无外部依赖。

## 现状

`gomoryhu/core.py` 提供 `GomoryHu`，用逐对点最大流一条朴素路：

- `nodes`：图里全部结点编号，按升序
- `node_count`：结点个数
- `has_edge`：两点之间是否存在一条边
- `pair_cut`：两点间最小割容量、可及割侧点集与本次增广次数
- `all_pairs_cuts`：对所有无序点对逐一求最小割容量
- `pair_disjoint`：逐对点口径下判断一点能否把另两点隔开
- `augment_count`：自上次清零以来累计的增广次数

现状是朴素做法：每一对点都从头单独跑一遍最大流，任意两点都重算一遍，求全部
点对时代价按点对数量乘以一次最大流的时间上涨。最大流用整数容量与确定性增广
顺序，结果可复现。异常基类是 `Erro`，输入不合法抛 `GraphError`，查询未登记
结点抛 `UnknownNodeError`。

## 问题

没有戈莫里胡树那样维护割侧代表、每次只跑点数减一次最大流的做法，点一多就
按点对数量成倍累加；也没有第二条独立口径能在固定输入上与非树做法逐项对照。
