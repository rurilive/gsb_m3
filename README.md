# primesieve

一个只用 Python 标准库的素数筛与整数分解小工具。包内模块 sieve.py 提供
Sieve 类，围绕一个上界做判素与相关统计：primes 求不超过上界的全部素数，
is_prime 判定单个整数是否素数，factorize 与 factorize_all 分解一个或一批
整数，euler_phi 求欧拉函数值，count_primes 统计某闭区间内的素数个数。

## 现状

判素一律从二试到该数的平方根逐个试除；分解一律从二开始反复试除因子；求
素数、求欧拉函数值、统计区间素数个数也都走同一套试除。数小、上界低的时
候直观可靠，结果也一目了然。

## 问题

逐数试除的计算量随被处理数的规模平方级增长，上界一大就慢得刺眼，分解时
也反复试除同样的因子。当前实现既没有一次线性时间筛出全部素数的路径，也
没有顺带记录每个数最小质因子的表，更没有据该表做近似对数级快速分解的手
段，无法说明一条更聪明的做法到底省了多少。

## 目标

把 Sieve 从逐数试除扩成以线性筛为核心的素数筛与快速分解工具：一趟线性时
间筛出不超过上界的全部素数，同时顺带记录每个数的最小质因子，据该表做近
似对数级的快速质因数分解；在素数表与最小质因子表之上支撑求欧拉函数值、
统计某范围内素数个数、批量分解多个数等能力；新老两路对同一批输入逐项一
致；暴露逐数试除次数与线性筛标记次数的差距；覆盖上界为零或一、上界为素
数、素数幂、含大素因子、分解一和零的边界口径、重复分解同一数确定性等；
异常统一继承 Erro 基类并快速失败；基线那套逐数试除路径不许删。
