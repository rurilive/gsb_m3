# bit2d

纯标准库的二维整数网格工具雏形，无外部依赖。

## 现状

bit2d/grid.py 提供一个 NaiveGrid：

- 建网格：按行列数建一张全零网格，bool 不算整数，负数行列报 ValueError
- shape 与 value_at：取回行列数，按下标取回单个格子，越界报 IndexError
- to_matrix：返回底层数据的一份行优先副本，改副本不影响网格
- update：把某个格子加上一个增量，返回加完之后的新值，越界报 IndexError
- query：子矩阵求和的唯一入口，半开区间 [row1, row2] x [col1, col2]，
  空矩形返回 0，这一步把矩形里的每个格子挨个累加，摸过几个格子就是几个
  格子的代价
- dense_prefix 与 rebuild_snapshot：每次都由底层数据从零重算整张二维前缀和表
- last_cost 与 rebuild_count：上一次查询摸过的格子数，以及前缀和表被重建的次数

子矩阵查询只有逐格累加这一条路，矩形一大就要把矩形里每个格子都摸一遍；
点更新也只是就地改一个格子，改完之后原先算过的结果全部作废，下一次查询
还得从头再扫；没有二维树状数组，没有按二进制跳跃的下标结构，没有差分，
也没有把矩形面积降下来的任何索引。

## 目标（见任务描述）

在当前朴素逐格累加的基础上扩成二维树状数组，全部仍放在 bit2d 包里，
纯标准库。约束：

- 现有行为与 tests/test_grid.py 基线保持一致（基线一个字不改）
- 新行为另开 tests/test_bit2d.py，用固定种子与逐字断言
- 二维树状数组只该换掉算的路径，不该改结果：子矩阵和、点更新后的增量维护
  都要与逐格累加或前缀和重建口径逐项一致
