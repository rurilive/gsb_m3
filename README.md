# mergeseq

一个只用 Python 标准库的序列区间统计工具包。包内模块 mergeable.py 提供 MergeSeq
类，把一条序列的历次修改各自留一个版本：set 改一个位置生成新版本，range_sum 求
区间和，range_min 与 range_max 求区间最值，kth_smallest 求区间第几小，version 与
use 看和切当前版本，taken 出累计扫过的位置数，stats 出内存与版本计数快照。

## 现状

任何查询都在原序列上从头扫过目标区间的每一个位置：区间求和逐个位置累加，区间最值
逐个位置比较取极值，区间第几小切出那一段整段排序再取下标。单点赋值则把当前那条序
列整份复制一份改成副本。规模小时结果一眼能看穿，也从来没有出过错。

## 问题

每一次查询的代价都与区间长度成正比，连续查同一段时把同一段反复走了很多遍，查询之
间没有任何复用，也没有任何挂在序列之上的加速结构。既没有以线段树为核心的区间聚合，
也没有把两棵线段树按位置归并成一棵的能力，更没有只增不改的持久化节点去支撑历史版
本查询。单点修改之后想按时间回溯到任意旧版本区间统计，基线同样给不出对数级的路子。

## 目标

把 MergeSeq 从从头重扫扩成以线段树为核心的统计工具集：单点修改走树上的路径更新、
区间聚合走结点区间归并，支持把两棵等长线段树按位置归并合并成一棵；再用只增不改的
持久化节点支持历史版本查询，指定版本上的区间统计与新老两路对同一批操作逐项一致。
要能暴露朴素重扫访问位置数与树访问节点数之间的差距，覆盖空区间、单元素、版本回溯
到最初或中间、修改成原值、合并空树等边界；异常统一继承 MergeableSegError 基类；基
线那条朴素路径一条都不许删，固定输入重复跑结果一致，不依赖模块级可变状态。

## 运行

    python3 demo.py
    python3 -m unittest discover -s tests
