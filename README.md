# beatsx

可变整数序列的区间操作工具包，纯标准库，无外部依赖。

## 现状

`beatsx/segment.py` 提供 `BeatsSeq`，内部只用一个普通列表存数据：

- `BeatsSeq(values)`：用一列整数构造，非整数或布尔量一律拒绝
- `range_chmin(lo, hi, upper)`：区间取最小值，把 `[lo, hi)` 里超过 `upper`
  的元素压到 `upper`，返回被压下去的数值总和
- `range_add(lo, hi, delta)` / `range_assign(lo, hi, value)`：区间加与区间赋值
- `range_sum(lo, hi)` / `range_qmin(lo, hi)` / `range_qmax(lo, hi)`：区间求和与区间最值
- `values()` / `op_count()`：整份数据副本与已执行的操作次数
- `touched()`：访问量统计快照，基线把元素总数当作访问次数

全部区间都是左闭右开口径，非法区间立刻报错。

## 问题

每类操作都从区间左端点走到右端点：取最小值这种能把一大片元素整体压低的
场合也逐元素比对改写，求和与最值则切片后逐项重扫。区间一大，落点的元素
没几个，白扫的却是一整段，访问次数与被改写元素数之间的差距无从体现。

## 目标

在当前基础上补出一棵吉司机线段树：节点维护最大值、次大值与最大值个数，
区间取最小值只在能整体压低最大值的节点上打标记、向下递归无法整体处理的
孩子，并在其上支持区间加、区间赋值、区间求和、区间最值，可选支持区间历史
最大值，见任务描述。约束：

- 现有行为与 `tests/test_segment.py` 基线保持一致（基线一个字不改）
- 纯标准库，Python 3.10+
- 必须量出节点访问次数与被改写元素数的差距，用计数器给出证据

## 运行

```bash
python3 demo.py
python3 -m unittest discover -s tests -v
```
