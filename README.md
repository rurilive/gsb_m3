# hldquery

树上路径与子树查询工具包，纯标准库，无外部依赖。给一棵带点权的树，回答两类
问题：任意两点之间的路径信息，以及某点子树的信息；并支持单点改权。

## 现状

朴素实现，能算对但规模一大就慢。

- `hldquery/naive.py`：`build_tree()` 把父指针与点权规整成字典，`node_path()`
  沿父指针回升出两点路径，`chain_end_naive()` 自一点向根走、遇到父亲有多个
  孩子就停下；`PathQuerier` 每次查询都沿父指针逐级走或整棵子树枚举，
  `path_sum()` 求路径权值和，`path_max()` 求路径最大值，`subtree_sum()` 求
  子树权值和，`update()` 单点改权，`best_path()` 枚举全部点对找路径和最大的
  一对并给出端点，`walk_steps()` 与 `step_count()` 暴露逐步次数；异常基类
  `QueryError` 与两个子类也在本文件。

单次路径查询是线性的，单次子树查询要遍历整棵子树；查询与修改一多，总代价随
规模迅速膨胀。

## 问题

没有把树拆成链来批量维护区间，每次查询都从零重走一遍；路径与子树两类查询各
自为政，没有共享的次序与区间结构；也没有可对照的规模指标，慢在哪看不出来。
