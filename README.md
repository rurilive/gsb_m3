# dlx

纯标准库的精确覆盖求解工具雏形，无外部依赖。

## 现状

dlx/core.py 提供一条朴素能力，全靠把矩阵当成二维表、按行号从小到大回溯枚举：

- solve：返回一个精确覆盖解，按行号升序给出行号列表，无解返回空列表
- solve_all：枚举全部解，按行号列表字典序升序返回，可截断输出条数
- minimum_solution：返回选中行数最少的解，并列时取字典序最小
- solution_count：解的个数
- is_exact_cover：判断给定行集合是不是一个精确覆盖
- column_coverage：某一行覆盖了哪些列
- conflict_columns：给定行集合里互相冲突的列
- search_steps：求解探测过的状态规模，用来做规模对照

每层递归都对全部尚未占用的列做线性扫描，不看哪一列可选行最少，也不做列头跳
转，同一批行组合会在不同分支上被反复展开，规模一大就指数级变慢；求全部解、
求行数最少的解，也是各自把整棵枚举树重走一遍，彼此不共用口径。

## 问题

行数一上去，展开的状态数就指数膨胀；求一个解与求最优解走的是同一套枚举，重复
劳动；想把舞蹈链做法与朴素验证路互相印证，也缺入口，覆盖剔除次数与朴素探测规
模的对照更是读不到。

## 目标

在当前基础上补出按列头双向循环十字链表组织的舞蹈链做法与一条独立的朴素验证
路，两路对同一批矩阵逐项一致，接上无解、唯一解、多解、空矩阵、单行单列这些
边界，暴露覆盖剔除次数与朴素探测规模的对照，见任务描述。约束：

- 现有行为与 tests/test_core.py 基线保持一致（基线一个字不改）
- 纯标准库
- 两路结果逐项一致，两路不许互相调用

```bash
python3 demo.py

```
