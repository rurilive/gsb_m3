# ledgerbook

一个纯标准库的复式记账账本，无外部依赖。记账系统、报销工具里都要把一笔业务的
钱记下来再算清余额，ledgerbook 就是干这件事的那一层。

## 现状

- `ledgerbook/ledger.py`：`Ledger` 只有一张收支流水，`record_in` 与 `record_out`
  各追加一条 `Flow`，`balance()` 是收入合计减支出合计。
- `ledgerbook/errors.py`：`LedgerError` 是全部可诊断错误的基类，`InvalidAmount`
  覆盖金额非法一类。
- 金额一律是整数分，`_check_amount` 只收正整数，浮点、布尔与字符串一律拒绝。

现有实现没有科目概念，一笔业务只落成一条流向为 in 或 out 的流水；没有借贷两侧，
也就没有平衡校验；跨科目、跨期间的汇总无从谈起；流水一旦记下不能锁定也不能冲销。

## 问题

只有单向流水时，一笔业务只留下一个数字，钱的来处与去处没法同时表达；想按科目
看余额、再按父子科目逐级汇总，现有结构里没有落脚点。业务发生在哪一天、归到哪个
会计期间、期间结没结账都无处记录，已结账的期间照样能被后续改动。也拿不到一张
可以自证的试算表，不知道借方与贷方到底相不相等。外部对账数据来了以后，差在哪里、
差多少只能人工翻账。写错的一笔只能删了重记，原分录保不住。

## 目标

见任务描述。约束：

- 现有行为与 `tests/test_ledger.py` 基线一致（基线一个字不改）
- 纯标准库，Python 3.10+
- 金额不得出现浮点误差，全程用整数分或 Decimal
- 不平衡的交易必须整笔拒绝，不许只落一半

```bash
python3 -m unittest discover -s tests -v
```
