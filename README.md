# treaplib

一个纯标准库的小序列包。当前只提供一个对外类，用来承载"按位置读写一串元素"的基础需求。

## 现状

包里的核心类内部就是一个普通的 Python 列表。按下标取值、按下标改值、按下标插入、
按下标删除、翻转半开区间、把一段子区间剪切下来返回，全部直接落在这一份列表上。
插入与删除用列表自己的做法，会把后面一整段元素整体往后挪或往前搬；区间翻转靠一个
循环逐个交换两端的元素；剪切则是切一段副本再把原处的这一段抹掉。

## 问题

这份实现的功能是对的，代价却随规模一路走高。每一次插入或删除都要搬动后面的一整段，
最坏的时候一次改动几乎动了整份数据；区间翻转逐对交换，段越长越慢；剪切同样要复制并
搬移。反复做这类局部改动，开销就会一直累加，既撑不住大一点的数据量，也没有任何可以
复用的中间结构，留不出继续演进的空间。

## 目标

在不改变对外方法名、参数与返回值的前提下，把底层换成以隐式平衡二叉树为核心的序列，
让它支持按子树大小定位下标，并把拆分与合并作为两种基本操作，其余操作都由它们组合而
成。插入删除、区间翻转、区间剪切拼接都要与逐项暴力结果一致，并给出可读的树高与访问
计数，让对数级的说法能被测量。
