# colitext

最朴素的单机字符串缓冲，纯标准库，无外部依赖。

## 现状

colitext/buffer.py提供TextBuf：

- 构造时可传入初始文本，默认空串
- insert(index, text)在下标处插入一段文本并返回自身，空文本按无操作处理
- delete(index, count)从下标起删除若干字符并返回自身，count为0按无操作处理
- text()返回当前文本的副本，改动副本不影响缓冲自身
- 越界下标、非字符串文本、非法删除数量在调用处抛ColitextError

## 目标（见任务描述）

在现有 TextBuf 之上把 colitext 扩成一个可跨副本收敛的协同文本：插入不再用
裸下标而用相对既有元素的位置标识，两个副本各自独立插入再合并后位置不会错乱；
两个副本对同一段文本并发插入与删除，交换操作日志后收敛到完全相同的文本，
操作应用顺序不同不影响最终结果；删除用标记而非物理移除，先插后删与并行插删
都不产生幽灵字符或有理位置崩塌；合并满足交换律与幂等，运行时提供断言入口校验；
可把已确认区间压缩成快照，快照加剩余操作重放与全量重放一致。全部仍在 colitext
包内，纯标准库。
